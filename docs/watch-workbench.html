What to look for

  1. Axis dynamics: physical parameters and PID settings beside a moving mechanism, position response and force command.
  2. Control analysis: root-locus poles, loop magnitude/phase, and the finite Nyquist trace around −1.
  3. Robot kinematics: joint and link controls, the spatial arm, tool coordinates and a live trajectory trace.
  4. System builder: drag an OUT circle onto an IN circle, or click OUT then IN. A dashed preview and highlighted input guide wiring. Edit parameters and inspect solver results in scopes.

The written walkthrough explains these controls without requiring video playback.

Keep the model boundaries visible

  • The axis simulation has sampled control and force limits. The root/frequency plots analyze a separate ideal continuous model.
  • The finite Nyquist trace does not supply a completed-contour stability proof.
  • The arm demonstrates geometry and forward kinematics, without torque, collision or contact dynamics.
  • The builder carries scalar signals. Signal units and physical assumptions remain the model author's responsibility.

Local playback and caption help

Keep this HTML file in docs/ with the sibling media/ directory. GitHub may show the player source or an MP4 download instead of running this page; clone or download the files first.

If your browser restricts captions when opening a local file directly, serve only this documentation directory on loopback. From the repository root:

python3 -m http.server 8766 --bind 127.0.0.1 --directory docs

Then open http://127.0.0.1:8766/watch-workbench.html. Stop the local server when finished. The page has no CDN, remote font, analytics or upload service; its video and captions are repository files.
